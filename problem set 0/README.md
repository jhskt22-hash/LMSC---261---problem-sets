# The algorithm is trying to find the name ‘Smith’, and then call Mike.
This is being done by dividing the book up in halves repeatedly to find the name as efficiently as possible, making its search parameter smaller and smaller. If the solution is *not* found, the algorithm quits. If the solution **is** found, it calls Mike.
